# arraylib

Лабораторная работа № 2.
Кроссплатформенная динамическая библиотека операций над массивами.

## Среда разработки

- VS Code и WSL
- C++17
- g++
- CMake
- Git

## Функции библиотеки

- arr_sum — сумма элементов
- arr_max — максимальный элемент
- arr_min — минимальный элемент
- arr_average — среднее арифметическое
- arr_count_positive — количество положительных элементов
- arr_count_negative — количество отрицательных элементов
- arr_count_zero — количество нулей
- arr_product — произведение элементов
- arr_median — медиана без изменения исходного массива

## Требования к данным

Массив должен быть непустым.
Размер передаётся параметром std::size_t.
При вычислении суммы и произведения необходимо избегать переполнения int.

## Вариант 22. Амплитуда аудиосигнала

Исходный массив:
12, 45, 67, 23, 89, 54, 31, 76, 18, 95, 42, 60.

Программа вычисляет сумму, максимум, минимум,
среднюю амплитуду и количество значений выше 60.

### Сборка и запуск в WSL

```bash
cmake -S . -B build -DBUILD_TESTING=ON
cmake --build build --target variant_22
./build/variant_22
```

### Ожидаемые результаты

- Сумма: 612
- Максимум: 95
- Минимум: 12
- Среднее: 51.00
- Количество значений выше 60: 4
